Akkusativ vs Dativ

A confusão clássica! Use o Akkusativ para indicar movimento de um ponto A para um ponto B (Wohin?). Use o Dativ para indicar localização ou posição estática (Wo?).

arrow_forward

Ich hänge das Bild an die Wand.

Akkusativ (Movimento: Eu penduro o quadro na parede).

location_on

Das Bild hängt an der Wand.

Dativ (Estado: O quadro está pendurado na parede).
